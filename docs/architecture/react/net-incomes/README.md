# 手取り収入 Reactアーキテクチャ設計

## 1. 概要

本ディレクトリでは、

手取り収入に関するAPIを

React・TypeScriptから利用する際の

フロントエンド実装方針を定義する。

対象APIは以下とする。

* INC-001 手取り収入一覧取得
* INC-002 手取り収入登録
* INC-003 手取り収入詳細取得
* INC-004 手取り収入更新
* INC-005 平均手取り収入取得

手取り収入は、

利用者ごとに対象年月単位で管理する。

収入が発生しなかった年月についても、

未登録とは区別し、

金額0円の有効なデータとして扱う。

## 2. React・TypeScript実装方針

APIとの通信では、

リクエスト、

クエリパラメータおよび

レスポンスの型を定義し、

通信データを型安全に扱う。

対象年月は、

日付ではなく業務上の年月として、

`YYYY-MM`形式の文字列で保持する。

手取り収入金額については、

`0`を未入力として扱わず、

有効な金額として表示・送信する。

備考が未設定の場合は、

`null`として扱う。

## 3. 画面間の連携

手取り収入一覧から編集する場合は、

INC-003で対象データを取得し、

編集画面の初期値として使用する。

```text
INC-001 一覧取得
    ↓
INC-003 詳細取得
    ↓
INC-004 更新
```

新規登録ではINC-002を使用し、

登録成功後は一覧画面または

対象データを確認できる画面へ遷移する。

## 4. 平均手取り収入

INC-005では、

判定対象年月直前の連続する3か月から

バックエンドで算出された平均手取り収入を取得する。

フロントエンドでは、

平均値および算出対象年月を再計算せず、

APIから返却された

`averageAmount`および

`calculatedMonths`を使用する。

データ不足の場合は、

システムエラーではなく、

入力が必要な業務状態として表示する。

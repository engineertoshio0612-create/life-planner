# 資産状況 Reactアーキテクチャ設計

## 1. 概要

本ディレクトリでは、資産状況に関するAPIをReact・TypeScriptから利用する際の、フロントエンドにおける実装方針および責務分離方針を定義する。

対象APIは以下とする。

* AST-001 現在資産状況取得
* AST-002 指定年月資産状況取得
* AST-003 資産推移取得

資産状況APIは、確定済み月末資産状況をもとに、総資産、利用可能資産、資産口座別資産額および保有商品別資産額を取得する読み取り専用APIである。

React側では、バックエンドで算出された資産額を正式値として扱い、月末資産残高や商品別月末評価額から独自に再集計しない。

```text
React Component
    ↓
Custom Hook
    ↓
React Query
    ↓
API Client
    ↓
AST API
```

API呼び出しおよびサーバー状態の管理はReact Query等へ集約し、画面コンポーネントは取得結果の表示および利用者操作を主な責務とする。

## 2. APIの使い分け

```text
最新の確定済み資産状況
    → AST-001

指定年月の確定済み資産状況
    → AST-002

複数月の資産推移
    → AST-003
```

AST-001およびAST-002を複数回呼び出して資産推移を生成するなど、各APIの責務をフロントエンド側で置き換えない。

また、未取得、正常な0円、空配列、欠損月、前月比較不可などをそれぞれ異なる状態として扱う。

月末資産状況の確定・確定解除によって資産状況が変化する可能性があるため、SNP系APIの成功後は関連するQueryを必要に応じてinvalidateする。

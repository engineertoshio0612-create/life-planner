# 月末資産残高 Reactアーキテクチャ設計

## 1. 概要

本ディレクトリでは、
月末資産残高（Asset Balance）に関するAPIを
React・TypeScriptから利用する際の
フロントエンド実装方針を定義する。

月末資産残高は、
月末資産状況（Month End Asset Snapshot）に対して、
資産口座単位で記録する対象年月時点の残高を表す。

フロントエンドでは、
月末資産残高の一覧表示、登録、更新を担当し、
業務ルールの最終的な保証はバックエンドへ委ねる。

---

## 2. 対象API

| API ID  | API名       | 役割                    |
| ------- | ---------- | --------------------- |
| BAL-001 | 月末資産残高一覧取得 | 対象年月の資産口座と残高登録状態を取得する |
| BAL-002 | 月末資産残高登録   | 未登録の月末資産残高を新規登録する     |
| BAL-003 | 月末資産残高更新   | 登録済みの月末資産残高を更新する      |

詳細は以下を参照する。

* [BAL-001 月末資産残高一覧取得](./bal-001-list.md)
* [BAL-002 月末資産残高登録](./bal-002-create.md)
* [BAL-003 月末資産残高更新](./bal-003-update.md)

---

## 3. フロントエンド実装方針

月末資産残高の登録状態は、
BAL-001が返却する`balance`によって判定する。

```text
balance === null
    → 未登録
    → BAL-002で登録

balance !== null
    → 登録済み
    → BAL-003で更新
```

`balance = 0`は0円で登録済みの状態であり、
未登録とは明確に区別する。

そのため、`if (!balance)`のような
truthy / falsyによる登録状態の判定は行わない。

---

## 4. 月末資産状況との関係

BAL系APIの操作対象は、
`snapshotId`によって特定される月末資産状況に紐づく。

月末資産状況が確定済みの場合、
月末資産残高の登録・更新はできない。

画面上で編集可否を制御する場合は、
SNP-003 月末資産状況詳細取得APIから
`confirmed`を取得して利用する。

ただし、フロントエンドの制御は補助的なものとし、
登録・更新可否の最終判断はバックエンドで行う。

---

## 5. データ再取得

BAL-002またはBAL-003の成功後は、
必要に応じてBAL-001やSNP-003を再取得し、
画面をバックエンドの最新状態と同期する。

React Query等を使用する場合は、
対象の`snapshotId`に対応するクエリを
invalidateする方式を基本とする。

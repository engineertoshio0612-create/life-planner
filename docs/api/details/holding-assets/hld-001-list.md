# HLD-001 保有商品一覧取得

## 1. 概要

操作対象となる利用者に帰属する
保有商品の一覧を取得する。

利用中の保有商品だけでなく、
無効化された保有商品も取得対象とする。

保有商品ごとに、
所属する資産口座および現在の利用状態を返却する。

---

## 2. ユースケース

利用者は、
登録済みの保有商品を一覧で確認する。

一覧では、
以下の情報を確認できる。

- 保有商品名
- 所属する資産口座
- 利用開始年月
- 利用状態

無効化された保有商品も表示し、
利用中の保有商品と区別できるようにする。

---

## 3. エンドポイント

```http
GET /api/v1/holding-assets
```

---

## 4. HTTPメソッド

```http
GET
```

本APIは、
保有商品の参照のみを行う。

---

## 5. 認証・利用者の扱い

Phase1では、
認証機能を実装しない。

操作対象となる利用者は、
`X-User-Id`
リクエストヘッダーで指定する。

```http
X-User-Id: 1
```

指定された利用者に帰属する
保有商品のみ取得する。

---

## 6. パスパラメータ

なし。

---

## 7. クエリパラメータ

なし。

Phase1では、
以下の機能を提供しない。

- 商品名検索
- 資産口座による絞り込み
- 利用状態による絞り込み
- 並び順変更
- ページネーション

保有商品数は少ないことを前提とし、
全件取得する。

---

### 8.1 必須ヘッダー

|ヘッダー|必須|説明|
|---|:---:|---|
|X-User-Id|○|操作対象利用者|

---

### 8.2 共通ヘッダー

|ヘッダー|必須|説明|
|---|:---:|---|
|Accept|○|application/json|

---

## 9. リクエストボディ

なし。

---

## 10. バリデーション

以下を検証する。

- X-User-Idが指定されていること
- X-User-Idが正しい形式であること
- 指定された利用者が存在すること
- 指定された利用者が論理削除されていないこと

---

## 11. 業務ルール

- 指定された利用者の保有商品のみ取得する。
- 他利用者の保有商品は取得しない。
- 利用中および無効化済み保有商品を取得する。
- 商品単位で管理する資産口座に属する保有商品のみ取得する。
- 無効化済み保有商品は利用状態が判別できる形式で返却する。
- 利用中の保有商品を先に表示する。
- 同一利用状態では商品名の昇順で表示する。
- 保有商品の所属資産口座も返却する。
- データベース内部カラムは公開しない。

---

## 12. 表示順

保有商品は、
以下の順序で表示する。

1. 利用中
2. 無効化済み
3. 商品名昇順

利用状態は、
`holding_assets.deleted_at`
から判定する。

---

## 13. 処理フロー

```text
リクエスト受付
    ↓
リクエストID生成
    ↓
X-User-Id検証
    ↓
操作対象利用者特定
    ↓
保有商品取得
    ↓
所属資産口座取得
    ↓
利用状態・商品名順に並び替え
    ↓
API Resourceへ変換
    ↓
正常レスポンス返却
```

---

トランザクションは使用しない。

## 15. 排他制御

## 16. 成功レスポンス

### HTTPステータス

```http
200 OK
```

### レスポンス例

```json
{
  "data": [
    {
      "id": "1",
      "assetAccountId": "3",
      "assetAccountName": "SBI証券",
      "name": "eMAXIS Slim 全世界株式",
      "startYearMonth": "2026-01",
      "isEnabled": true
    },
    {
      "id": "2",
      "assetAccountId": "3",
      "assetAccountName": "SBI証券",
      "name": "ニッセイ外国株式",
      "startYearMonth": "2026-02",
      "isEnabled": false
    }
  ]
}
```

---

## 17. レスポンス項目

|項目|型|NULL|説明|
|---|---|:---:|---|
|id|string|×|保有商品ID|
|assetAccountId|string|×|資産口座ID|
|assetAccountName|string|×|資産口座名|
|name|string|×|保有商品名|
|startYearMonth|string|×|利用開始年月|
|isEnabled|boolean|×|利用状態|

---

## 18. データが存在しない場合

保有商品が存在しない場合も、

```http
200 OK
```

を返却する。

```json
{
  "data": []
}
```

共通エラーレスポンス形式を使用する。

## 20. HTTPステータス

|HTTPステータス|条件|
|---:|---|
|200|取得成功|
|400|利用者指定不正|
|404|利用者不存在|
|500|サーバーエラー|

|エラーコード|HTTP|内容|
|---|---:|---|

|USER_NOT_FOUND|404|利用者不存在|
|INTERNAL_SERVER_ERROR|500|サーバーエラー|

- 利用者不存在

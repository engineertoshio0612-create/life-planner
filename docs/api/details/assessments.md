# 目的達成判定API詳細設計

## 1. 概要

本ドキュメントでは、
目的達成判定に関するAPIの詳細仕様を定義する。

目的達成判定APIでは、
操作対象となる利用者について、
登録されている目的と資産状況をもとに
目的達成可否を判定する。

また、
実行した目的達成判定の結果を
目的達成判定履歴として保存し、
過去の判定結果を参照できるようにする。

Phase1では、
認証機能を実装しない。

操作対象となる利用者は、
`X-User-Id`
リクエストヘッダーで指定する。

本API群では、
他の利用者に属する目的、
資産情報および
目的達成判定履歴を
操作・参照できないようにする。

目的達成判定に使用する具体的な計算方法、
判定条件および
判定不可となる条件については、
機能要件および
目的達成判定に関する業務ルールに従う。

---

## 2. 対象API

本ドキュメントでは、
以下のAPIを対象とする。

| API ID | API名 | HTTPメソッド | URL |
|---|---|---|---|
| ASM-001 | 目的達成判定実行 | POST | `/api/v1/objectives/{objectiveId}/assessments` |
| ASM-002 | 目的達成判定履歴一覧取得 | GET | `/api/v1/objectives/{objectiveId}/assessments` |
| ASM-003 | 目的達成判定履歴詳細取得 | GET | `/api/v1/objectives/{objectiveId}/assessments/{assessmentId}` |

各APIの責務は、
以下のとおりとする。

### ASM-001 目的達成判定実行

指定された目的について、
現在利用可能な判定材料をもとに
目的達成判定を実行する。

判定結果は、
目的達成判定履歴として保存する。

---

### ASM-002 目的達成判定履歴一覧取得

指定された目的について、
過去に実行した
目的達成判定履歴の一覧を取得する。

目的達成判定そのものは
実行しない。

---

### ASM-003 目的達成判定履歴詳細取得

指定された目的について、
特定の目的達成判定履歴の
詳細を取得する。

目的達成判定そのものは
実行しない。

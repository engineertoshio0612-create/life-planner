# 資産状況API テスト設計

## 1. 概要

本ディレクトリでは、資産状況に関するAPIのテスト方針および主要なテスト観点を定義する。

対象APIは以下とする。

* AST-001 現在資産状況取得
* AST-002 指定年月資産状況取得
* AST-003 資産推移取得

資産状況APIでは、確定済みの`month_end_asset_snapshots`を基点として、月末資産残高、商品別月末評価額および対象年月時点の利用可能資産設定から資産状況を算出する。

テストでは、主に以下を確認する。

* 確定済み月末資産状況のみが取得対象となること
* 操作対象利用者以外のデータが混入しないこと
* 口座単位では`month_end_asset_balances.balance`を使用すること
* 商品単位では`month_end_holding_values.value`を使用すること
* 月末資産残高と商品別月末評価額を二重計上しないこと
* 総資産および利用可能資産が正しく算出されること
* 対象年月時点の利用可能資産設定が使用されること
* 0円とデータ不存在を区別すること
* GET APIとして副作用が発生しないこと
* 正常・異常レスポンスがAPI共通方針に従うこと

```text
AST-001
    → 最新の確定済み資産状況

AST-002
    → 指定年月の確定済み資産状況

AST-003
    → 指定期間の確定済み資産推移
```

AST-003では、未確定月やデータ不存在月を0円で補完しないこと、および暦上の前月が比較可能な場合のみ前月差分を算出することも検証する。

また、AST-001・AST-002・AST-003で同一年月を参照した場合に、総資産、利用可能資産および資産内訳の整合性が保たれることを確認する。

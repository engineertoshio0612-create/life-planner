# 手取り収入 テスト設計

## 1. 概要

本ディレクトリでは、

手取り収入に関するAPIの

テスト方針および主要なテスト観点を定義する。

対象APIは以下とする。

* INC-001 手取り収入一覧取得
* INC-002 手取り収入登録
* INC-003 手取り収入詳細取得
* INC-004 手取り収入更新
* INC-005 平均手取り収入取得

手取り収入は、

利用者ごとに対象年月単位で管理し、

同一利用者・同一対象年月について

1件のみ登録できる。

収入が発生しなかった年月についても、

未登録とは区別し、

金額0円の有効なデータとして扱う。

## 2. 共通テスト方針

各APIでは、

正常系だけでなく、

以下の観点を確認する。

* `X-User-Id`による利用者特定
* 他利用者のデータへアクセスできないこと
* 入力値およびパラメータのバリデーション
* API共通方針に従ったレスポンス契約
* 共通エラーレスポンス
* 内部情報がレスポンスへ公開されないこと

登録・更新では、

対象年月の重複制御、

トランザクションおよび

同時実行時のデータ整合性を確認する。

## 3. 平均手取り収入

INC-005では、

判定対象年月直前の

連続する3か月が

正しく算出対象となることを確認する。

金額0円の月は算出対象へ含め、

未登録の月が1か月でも存在する場合は、

`NET_INCOME_DATA_INSUFFICIENT`となることを確認する。

また、

平均手取り収入は保存せず、

取得時点のデータから

都度算出されることを確認する。

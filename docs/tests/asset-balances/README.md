# 月末資産残高 テスト設計

## 1. 概要

本ディレクトリでは、  
月末資産残高（Asset Balance）に関するAPIの  
テスト方針および主要なテスト観点を定義する。

月末資産残高は、  
月末資産状況に対して、  
資産口座単位で記録する対象年月時点の残高を表す。

テストでは、正常系や入力値検証だけでなく、  
利用者境界、対象年月時点の利用可否、  
残高記録単位、確定状態などの  
業務ルールが正しく適用されることを確認する。

---

## 2. 対象API

| API ID | API名 | 主なテスト対象 |
|---|---|---|
| BAL-001 | 月末資産残高一覧取得 | 一覧対象、登録状態、利用者境界、副作用 |
| BAL-002 | 月末資産残高登録 | 新規登録、業務条件、重複防止、トランザクション |
| BAL-003 | 月末資産残高更新 | 既存残高更新、存在確認、冪等性、トランザクション |

詳細は以下を参照する。

- [BAL-001 月末資産残高一覧取得](./bal-001-list.md)
- [BAL-002 月末資産残高登録](./bal-002-create.md)
- [BAL-003 月末資産残高更新](./bal-003-update.md)

---

## 3. 共通テスト方針

BAL系APIでは、特に以下を共通して検証する。

- 操作対象利用者のデータだけを参照・更新できること
- 対象年月時点の資産口座の利用可能状態を基準に判定すること
- 残高記録単位が口座単位の資産口座だけを対象とすること
- `balance = 0`を有効な残高として扱うこと
- 未登録と0円を混同しないこと
- 確定済み月末資産状況への登録・更新を拒否すること
- エラー時に不完全なデータ変更が残らないこと
- BAL系APIの責務外となるデータへ副作用を発生させないこと

BAL-002は新規登録、BAL-003は既存レコードの更新を責務とし、  
登録と更新をupsertによって統合しない。

# HLD-001 保有商品一覧取得

## 1. 概要

本ドキュメントでは、HLD-001 保有商品一覧取得APIに対するテスト方針および主要なテスト観点を定義する。

本APIでは、操作対象となる利用者に帰属する保有商品が正しく取得されることを確認する。

取得対象には利用中の保有商品だけでなく無効化済みの保有商品も含まれ、それぞれについて所属する資産口座および現在の利用状態が正しく返却されることを確認する。

主に以下を確認する。

* 操作対象利用者に帰属する保有商品のみが取得されること
* 他利用者に帰属する保有商品が取得されないこと
* 所属する資産口座名が正しく返却されること
* 利用中および無効化済みの保有商品が取得されること
* 無効化済みの保有商品が `isEnabled=false` として返却されること
* 保有商品が仕様どおりの順序で返却されること
* ID項目が文字列として返却されること
* 保有商品が存在しない場合に `data: []` が返却されること
* 利用者未指定、利用者不存在およびサーバーエラー時に適切なエラーレスポンスが返却されること

一覧取得処理によってデータの登録・更新・削除が行われないことを前提とし、利用者境界、無効化済みデータの取得、レスポンス形式および表示順を中心に検証する。

---

## 2. テスト観点

### 正常系

- 保有商品一覧取得
- 所属資産口座名取得
- 利用中・無効化済み取得
- 商品名昇順
- IDが文字列

### 利用者境界

- 他利用者の商品取得不可

### データなし

- data:[]

### 無効化

- isEnabled=false

### 異常系

- 利用者未指定
- 利用者不存在
- サーバーエラー

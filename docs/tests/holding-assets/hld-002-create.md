# HLD-002 保有商品登録

## 1. 概要

本ドキュメントでは、HLD-002 保有商品登録APIに対するテスト方針および主要なテスト観点を定義する。

本APIでは、操作対象となる利用者に帰属する資産口座へ、保有商品を新規登録する処理を検証する。

登録対象となる資産口座は、残高記録単位が「商品単位」であり、かつ保有商品の利用開始年月時点で有効な資産口座に限定する。

主に以下を確認する。

* 保有商品の正常登録
* 利用者境界
* 所属資産口座の利用状態および残高記録単位
* 利用開始年月の整合性
* 同一資産口座内の商品名重複
* 入力値バリデーション
* トランザクションおよびデータ整合性
* レスポンス契約
* 異常系および共通エラーレスポンス

特に利用者境界については、他利用者に帰属する資産口座へ保有商品を登録できないことを確認する。

また、同一資産口座内に同名の利用中保有商品が存在する場合は登録を拒否する一方、別資産口座、別利用者または無効化済み保有商品と同名の場合は登録できることを確認する。

登録成功時は、`201 Created`が返却され、登録内容が`holding_assets`へ正しく保存されること、およびAPI共通方針に従ったレスポンス形式で登録結果が返却されることを検証する。

---

## 2. テスト観点

### 2.1 正常系

- 必須項目を指定して保有商品を登録できること
- 備考を指定せず登録できること
- 登録結果が `201 Created` で返却されること
- 登録した保有商品が `data` オブジェクトで返却されること
- IDが文字列で返却されること
- `isEnabled` が `true` で返却されること
- 商品種別がAPI用の列挙値で返却されること

### 2.2 利用者境界

- 操作対象利用者の資産口座へ登録できること
- 他の利用者の資産口座へ登録できないこと
- 他の利用者の資産口座を指定した場合に `404 Not Found` となること
- 登録された `user_id` が操作対象利用者と一致すること

### 2.3 所属資産口座

- 商品単位の資産口座へ登録できること
- 口座単位の資産口座へ登録できないこと
- 無効化済み資産口座へ登録できないこと
- 存在しない資産口座へ登録できないこと
- 所属資産口座の利用開始年月と同じ年月を指定できること
- 所属資産口座の利用開始年月より前を指定できないこと

### 2.4 重複

- 同一資産口座内に同名の利用中商品を登録できないこと
- 別の資産口座には同名商品を登録できること
- 別の利用者には同名商品を登録できること
- 無効化済み商品と同名の商品を新しい商品として登録できること
- 同時登録時もデータベース制約によって重複を防止できること

### 2.5 バリデーション

- `assetAccountId` が必須であること
- `name` が必須であること
- `productType` が必須であること
- `startYearMonth` が必須であること
- 商品名の最大文字数を超える場合にエラーとなること
- 未定義の商品種別でエラーとなること
- 不正な年月形式でエラーとなること
- 存在しない年月でエラーとなること
- 備考の最大文字数を超える場合にエラーとなること

### 2.6 トランザクション

- 登録途中で例外が発生した場合にロールバックされること
- エラー時に保有商品が登録されないこと

### 2.7 レスポンス契約

- JSONフィールド名が `camelCase` であること
- `userId` がレスポンスに含まれないこと
- `deletedAt` がレスポンスに含まれないこと
- データベースの数値コードをそのまま公開しないこと
- 備考未入力時に `memo` が `null` となること

### 2.8 異常系

- 想定外の例外発生時に `500 Internal Server Error` となること
- 共通エラーレスポンス形式で返却されること
- エラーレスポンスとログに同じリクエストIDが記録されること
- SQLやスタックトレースがレスポンスに含まれないこと

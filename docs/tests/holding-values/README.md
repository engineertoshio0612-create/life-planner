# 商品別月末評価額 テスト設計

## 1. 概要

本ディレクトリでは、
商品別月末評価額に関するAPIの
テスト方針およびテスト観点を定義する。

商品別月末評価額は、
残高記録単位が商品単位である資産口座について、
保有商品ごとの月末時点の評価額を管理する。

テストでは、
正常系だけでなく、
利用者境界、対象年月時点の状態、
確定状態、バリデーション、
副作用、トランザクション、
排他・同時実行、異常系などを確認する。

口座単位で管理する月末資産残高は、
VAL系APIのテスト対象外とし、
BAL系APIで扱う。

---

## 2. API一覧

| ID | 機能 | 主なテスト対象 |
|---|---|---|
| VAL-001 | 商品別月末評価額一覧取得 | 保存済み評価額の一覧取得 |
| VAL-002 | 商品別月末評価額登録 | 未登録評価額の新規登録 |
| VAL-003 | 商品別月末評価額更新 | 登録済み評価額の更新 |

VAL-002では既存データを上書きせず、
VAL-003では未登録データを新規作成しない。

---

## 3. 共通テスト方針

- `X-User-Id`による利用者境界を確認する
- `snapshotId`に対応する月末資産状況を対象とする
- 登録・更新は未確定の月末資産状況のみ許可する
- 資産口座・保有商品の利用可否は対象年月時点の状態で判定する
- 商品単位で残高を記録する資産口座のみVAL系APIの対象とする
- `value = 0`を有効値として扱い、未登録状態と区別する
- 登録と更新の責務を分離する
- 業務データへ意図しない副作用が発生しないことを確認する
- エラー時に内部情報や他利用者のデータ存在を公開しないことを確認する
